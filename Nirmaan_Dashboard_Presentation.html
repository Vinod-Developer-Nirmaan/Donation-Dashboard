Project Overview

🎯 Purpose

A comprehensive donation management dashboard designed for nirmaan.org to track, manage, and analyze charitable donations efficiently.

👥 Target Users

Non-profit administrators, finance teams, and organizational staff who manage donation records and donor relationships.

💡 Key Benefits

Real-time analytics, multi-currency support (INR & USD), automated reporting, and streamlined donation tracking.

🌐 Deployment

Cloud-based web application accessible from any device with responsive design for desktop and mobile users.

Database Structure

📋 Payments Table

CREATE TABLE payments (
  PaymentId INT PRIMARY KEY,
  ReceiptId VARCHAR(50),
  FullName VARCHAR(255),
  Email VARCHAR(255),
  Mobile VARCHAR(20),
  Amount DECIMAL(10,2),
  Currency ENUM('INR','USD'),
  TransactionFee DECIMAL(10,2),
  PaymentStatus VARCHAR(20),
  PaymentDate DATETIME,
  PaymentType VARCHAR(50),
  Cause VARCHAR(255),
  Reference VARCHAR(255),
  SubscriptionId VARCHAR(100),
  PAN VARCHAR(20),
  Address TEXT,
  Country VARCHAR(100),
  ZIP VARCHAR(20)
);

👤 Users Table

CREATE TABLE users (
  UserId INT PRIMARY KEY,
  FullName VARCHAR(255),
  Email VARCHAR(255) UNIQUE,
  Password VARCHAR(255),
  Role ENUM(
    'super_admin',
    'admin',
    'viewer'
  ),
  IsActive BOOLEAN,
  CreatedAt DATETIME,
  LastLogin DATETIME
);
6 / 10

Security Features

🔐 JWT Authentication

Secure token-based authentication with HTTP-only cookies. Tokens expire after 7 days for enhanced security.

🔑 Password Hashing

Bcrypt encryption with salt rounds for secure password storage. Passwords are never stored in plain text.

🛡️ Role-Based Access

Three-tier permission system (Super Admin, Admin, Viewer) controlling access to sensitive operations.

🚫 Protected Routes

Client and server-side route protection. Unauthorized users are redirected to login page.
